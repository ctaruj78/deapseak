🔧 Виправлення дублікатів полів ТО

Виявлена проблема

Дублікат полів ТО: В різних модальних вікнах є схожі поля для дат технічного обслуговування, що може призвести до плутанини та неузгодженості даних.
Конфліктні поля:
  • Основне модальне вікно: `lastMaintenance`, `nextMaintenance`
  • Модальне вікно звіту інспекції: `nextInspectionDue`

Порівняння: ДО / ПІСЛЯ

ДО (проблемне)
Основне модальне вікно:
<label>Останнє ТО</label>
<input id="lastMaintenance">

<label>Наступне ТО</label>
<input id="nextMaintenance">
Модальне вікно звіту:
<label>Наступна інспекція до</label>
<input id="nextInspectionDue">
Проблеми:
  • Дублювання функціональності
  • Плутанина для користувача
  • Можливість неузгодженості даних
  • Ручне оновлення в двох місцях
ПІСЛЯ (виправлено)
Основне модальне вікно:
<label>Останнє ТО</label>
<input id="lastMaintenance">

<label>Наступне ТО</label>
<input id="nextMaintenance">
Модальне вікно звіту:
<checkbox> Оновити дати ТО автоматично</checkbox>

<select>Періодичність для наступного ТО</select>
Переваги:
  • Автоматичне оновлення основних даних
  • Немає дублікатів
  • Логічний зв'язок між інспекцією та ТО
  • Контроль користувача над процесом

Технічні деталі виправлення

Зміни в HTML:
Замінено поле "Наступна інспекція до" на:
- Checkbox "Оновити дати ТО в основній інформації ліфта"
- Select "Періодичність для наступного ТО"
Зміни в JavaScript:
  • Функція saveInspectionReport(): додано логіку автоматичного розрахунку наступної дати ТО
  • Функція updateLiftMaintenanceDates(): нова функція для оновлення основних даних ліфта
  • Автоматична синхронізація: оновлення localStorage та глобальних змінних
Логіка роботи:
  1. Користувач заповнює звіт інспекції
  2. Вибирає чи оновлювати дати ТО автоматично
  3. Система використовує дату інспекції як "lastMaintenance"
  4. Розраховує "nextMaintenance" на основі періодичності
  5. Автоматично оновлює основні дані ліфта
  6. Перезавантажує таблицю ліфтів

Тестування

Відкрити сторінку ліфтів

Як протестувати

Кроки для тестування:
  1. Відкрийте сторінку ліфтів
  2. Додайте новий ліфт з датами ТО
  3. Клікніть на ліфт для відкриття деталей
  4. Натисніть "Додати звіт інспекції"
  5. Заповніть дату інспекції
  6. Переконайтеся що галочка "Оновити дати ТО" встановлена
  7. Збережіть звіт
  8. Перевірте, чи оновилися дати в основній інформації ліфта
Очікуваний результат: Після збереження звіту інспекції, поле "Останнє ТО" в основних даних ліфта повинно автоматично оновитися на дату проведеної інспекції, а "Наступне ТО" розрахуватися на основі вибраної періодичності.
