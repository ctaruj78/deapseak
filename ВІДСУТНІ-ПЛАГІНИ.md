## ⚠️ ВАЖЛИВІ ПРИМІТКИ

### 1. **Конфлікт QRCode бібліотек**
Зараз використовуються 2 різні:
- `qrcode@1.5.1` - більш сучасна, краща підтримка
- `qrcodejs@1.0.0` - старіша версія

**Рекомендація:** Уніфікувати на `qrcode@1.5.1` (вона краща).

### 2. **jQuery і Bootstrap**
Деякі сторінки завантажують jQuery/Bootstrap з CDN навіть коли вони є локально:
```html
<script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/bootstrap@4.6.0/dist/js/bootstrap.bundle.min.js"></script>
```

**Потрібно замінити на:**
```html
<script src="/plugins/jquery/jquery.min.js"></script>
<script src="/plugins/bootstrap/bootstrap.bundle.min.js"></script>
```

### 3. **AdminLTE**
Деякі сторінки завантажують з CDN:
```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/admin-lte@3.2/dist/css/adminlte.min.css">
<script src="https://cdn.jsdelivr.net/npm/admin-lte@3.2/dist/js/adminlte.min.js"></script>
```

**Потрібно замінити на:**
```html
<link rel="stylesheet" href="/plugins/adminlte/adminlte.min.css">
<script src="/plugins/adminlte/adminlte.min.js"></script>
```

### 4. **Google Fonts**
**Можна залишити CDN** тому що:
- ✅ Google CDN дуже швидкий (розташований по всьому світу)
- ✅ Браузери кешують шрифти між сайтами
- ✅ Автоматичне завантаження тільки потрібних символів
- ✅ Підтримка різних форматів (woff2, woff, ttf)

**АБО** завантажити локально якщо потрібна повна автономність.
