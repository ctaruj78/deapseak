# 🎛️ Налаштування системи по ролях

## 📋 Загальні налаштування (для всіх ролей)

Доступні для: **Admin, Dispatcher, Technician, Client**

- 🌍 **Мова інтерфейсу**: Українська 🇺🇦, English 🇬🇧, Português 🇵🇹
- 🎨 **Тема**: Світла / Темна / Автоматично
- 🔔 **Сповіщення**: Email, Push, SMS
- ⏰ **Часовий пояс**

---

## 👨‍💼 Admin - Адміністратор

### Додаткові секції:
1. **Системні налаштування** 🖥️
   - Автоматичне резервне копіювання
   - Режим обслуговування
   - Ліміт API запитів (за хвилину)
   - Таймаут сесії (хвилин)
   - Макс. розмір файлу для завантаження (MB)

2. **Резервне копіювання** 💾
   - Розклад бекапів (Щодня/Щотижня/Щомісяця)
   - Термін зберігання резервних копій (днів)
   - Автоматичне очищення старих копій

3. **Інтеграції** 🔌
   - Email інтеграція
   - SMS інтеграція
   - Telegram бот
   - Google Maps API

---

## �� Dispatcher - Диспетчер

### Додаткові секції:
1. **Робочий процес** 📋
   - Автоматичне призначення запитів
   - Фільтрувати за пріоритетом
   - Показувати тільки нові запити
   - Інтервал оновлення даних (секунди)

2. **Призначення техніків** 👨‍��
   - Враховувати навантаження техніка
   - Враховувати локацію
   - Враховувати спеціалізацію
   - Макс. призначень на одного техніка

---

## 🔧 Technician - Технік

### Додаткові секції:
1. **Робочі налаштування** 🛠️
   - Автоматичний check-in при прибутті
   - Обов'язкові фото після роботи
   - Офлайн режим (синхронізація)
   - Голосові нотатки

2. **Геолокація** 📍
   - Ділитися локацією з диспетчером
   - Відстежувати маршрут
   - Точність локації (Висока/Середня/Низька)

---

## 👤 Client - Клієнт

### Додаткові секції:
1. **Мої запити** 📝
   - Сповіщати про зміни статусу
   - Показувати історію запитів
   - Дозволити оцінювання роботи техніка
   - Зберігати платіжну інформацію

2. **Приватність** 🔒
   - Показувати email техніку
   - Показувати телефон техніку
   - Дозволити аналітику
   - Отримувати маркетингові email

## 🔄 Як працює універсальна сторінка

```javascript
// Автоматично визначає роль
const user = AuthManager.getCurrentUser();

// Завантажує відповідні налаштування
const roleSettings = getRoleSettings(user.role);

// Рендерить тільки те що потрібно для цієї ролі
renderSettings(roleSettings);
```

## 🚀 Використання

### В HTML сторінці:
```html
<!-- Підключити модулі -->
<script src="../../assets/js/i18n.js"></script>
<script src="../../assets/js/settings-manager.js"></script>
<script src="../../assets/js/modules/settings-page.js"></script>

<!-- Контейнер для налаштувань -->
<div id="settings-content"></div>

<!-- Ініціалізація -->
<script>
const settingsPage = new SettingsPage();
settingsPage.init();
</script>
```

### API Endpoints:
- `GET /api/settings` - Отримати налаштування
- `PUT /api/settings` - Оновити налаштування
- `PUT /api/settings/language` - Змінити мову
- `PUT /api/settings/theme` - Змінити тему
- `PUT /api/settings/notifications` - Налаштування сповіщень
- `POST /api/settings/reset` - Скинути до дефолту
