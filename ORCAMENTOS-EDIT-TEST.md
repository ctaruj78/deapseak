# 📝 Тест Редагування Орçаментів

## ✅ Що виправлено:

### 1. **Завантаження орçаменту для редагування/перегляду**
- Додано функцію `loadOrcamento(id, viewMode)` в `invoice-template.html`
- Автоматично завантажує дані при відкритті з `?id=...`
- Заповнює всі поля форми даними з MongoDB

### 2. **Режим перегляду (View Mode)**
- При відкритті з `?view=true` всі поля стають readonly
- Кнопки додавання/видалення сервісів вимкнені
- Кнопка "Salvar" прихована
- Відображається badge "Modo de Visualização"

### 3. **Оновлення орçаменту (PUT)**
- Функція `saveOrcamento()` тепер перевіряє `window.currentOrcamentoId`
- Якщо ID є - відправляє PUT запит для оновлення
- Якщо ID немає - відправляє POST запит для створення
- Зберігає `numero` та `data` при оновленні

### 4. **API_BASE_URL виправлено**
- Змінено з `http://localhost:5000` на `''` (порожній рядок)
- Тепер працює з relative URLs в GitHub Codespaces

## 🧪 Як протестувати:

### Тест 1: Переглянути орçаменто
1. Відкрийте `orcamentos-list.html`
2. Натисніть на кнопку "👁️ Ver" (сина кнопка)
3. **Очікуваний результат:**
   - Відкривається `invoice-template.html` з даними
   - Всі поля заповнені
   - Всі поля readonly (неможливо редагувати)
   - Відображається badge "Modo de Visualização"

### Тест 2: Редагувати орçаменто
1. Відкрийте `orcamentos-list.html`
2. Натисніть на кнопку "✏️ Editar" (жовта кнопка)
3. **Очікуваний результат:**
   - Відкривається `invoice-template.html` з даними
   - Всі поля заповнені
   - Поля можна редагувати
4. Змініть будь-яке поле (наприклад, кількість або ціну)
5. Натисніть "💾 Salvar Orçamento"
6. **Очікуваний результат:**
   - Повідомлення "✅ Orçamento XXX atualizado com sucesso!"
   - Орçаменто оновлено в базі даних
   - Пропозиція перейти до списку

### Тест 3: Створити новий орçаменто
1. Відкрийте `invoice-template.html` напряму
2. Заповніть форму
3. Натисніть "💾 Salvar Orçamento"
4. **Очікуваний результат:**
   - Повідомлення "✅ Orçamento XXX salvo com sucesso!"
   - Новий орçаменто створено

## 🔧 Технічні деталі:

### JavaScript функції:
```javascript
// Завантаження орçаменту
async function loadOrcamento(id, viewMode = false)

// Збереження (створення або оновлення)
async function saveOrcamento()
```

### URL параметри:
- `?id=<mongodb_id>` - ID орçаменту для завантаження
- `?view=true` - Режим перегляду (readonly)

### API endpoints:
- `GET /api/orcamentos/:id` - Отримати один орçаменто
- `POST /api/orcamentos` - Створити новий
- `PUT /api/orcamentos/:id` - Оновити існуючий
