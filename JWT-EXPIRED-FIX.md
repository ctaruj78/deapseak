# 🔐 JWT TOKEN EXPIRED - ВИПРАВЛЕННЯ

**Дата:** 7 Грудня 2024  
**Проблема:** "Невалідний токен: jwt expired" при використанні мікрофону в AI Assistant

---

## ❌ ПРОБЛЕМА

### Симптоми:
- 🎤 Натискання кнопки мікрофону
- 🗣️ Промова розпізнається успішно
- ❌ При відправці до API: **"Помилка: Невалідний токен: jwt expired"**
- 💬 Чат не працює

### Причина:
JWT токен має обмежений термін дії (зазвичай 1-24 години). Коли користувач залишає сторінку відкритою довго, токен простроюється і API відхиляє запити з кодом 401 Unauthorized.

---

## ✅ РІШЕННЯ

### 1. Додано перевірку статусу 401 в `sendChatMessage()`

```javascript
fetch(`${API_URL}/api/ai/chat`, {
    method: 'POST',
    headers: getAuthHeaders(),
    body: JSON.stringify({ message })
})
.then(res => {
    // Перевірка на помилку авторизації
    if (res.status === 401) {
        console.error('❌ JWT Token expired or invalid');
        
        // Показати повідомлення
        const errorMsg = '⚠️ Сесія прострочена. Будь ласка, увійдіть знову.';
        addChatMessage(errorMsg, false);
        
        // Очистити токени
        localStorage.removeItem('token');
        localStorage.removeItem('lm_token');
        localStorage.removeItem('deapseak_token');
        sessionStorage.removeItem('token');
        
        // Перенаправити на логін
        setTimeout(() => {
            if (confirm('Сесія прострочена. Перейти на сторінку входу?')) {
                window.location.href = '/pages/auth/login.html';
            }
        }, 2000);
        
        throw new Error('Unauthorized - JWT expired');
    }
    return res.json();
})
```

### 2. Додано перевірку токена при завантаженні сторінки

```javascript
document.addEventListener('DOMContentLoaded', function() {
    // Перевірка JWT токена
    const token = getAuthToken();
    if (!token) {
        console.warn('⚠️ JWT токен не знайдено');
        
        // Показати попередження через 2 секунди
        setTimeout(() => {
            if (!getAuthToken()) {
                const alert = document.createElement('div');
                alert.className = 'alert alert-warning alert-dismissible';
                alert.innerHTML = `
                    <strong>⚠️ Увага!</strong> Ви не авторизовані. 
                    <a href="/pages/auth/login.html">Увійдіть в систему</a> 
                    для повного функціоналу.
                `;
                document.body.appendChild(alert);
            }
        }, 2000);
    } else {
        console.log('✅ JWT токен знайдено');
    }
});
```

## 🔄 ЯК ПРАЦЮЄ ТЕПЕР

### Сценарій 1: Токен прострочений при використанні мікрофону

1. Користувач натискає 🎤
2. Говорить в мікрофон
3. Текст розпізнається і відправляється до API
4. **API відповідає 401 Unauthorized**
5. ✅ Система автоматично:
   - Показує повідомлення в чаті: "⚠️ Сесія прострочена"
   - Очищує старі токени з localStorage/sessionStorage
   - Через 2 сек показує confirm діалог
   - Перенаправляє на `/pages/auth/login.html`

### Сценарій 2: Користувач відкриває AI Assistant без токена

1. Сторінка завантажується
2. ✅ Система перевіряє наявність токена
3. Якщо немає:
   - Console: "⚠️ JWT токен не знайдено"
   - Через 2 сек: жовте попередження вгорі
   - Посилання на логін
4. Функціонал обмежений (тільки читання регуляцій)

### Сценарій 3: Токен валідний

1. Console: "✅ JWT токен знайдено"
2. Весь функціонал доступний:
   - 🎤 Голосове введення
   - 💬 Чат з AI
   - 📄 Завантаження PDF

       process.env.JWT_SECRET,
