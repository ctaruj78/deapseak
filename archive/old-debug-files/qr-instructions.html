QR Система DeapSeaK

Єдина система для управління QR-кодами ліфтів із підтримкою різних ролей користувачів

🔹 Генерація і управління QR-кодами
🔹 Сканування через камеру або файл
🔹 Різні інтерфейси для різних ролей
🔹 Статистика та аналітика

Як отримати доступ до QR системи

1Увійдіть в систему

Використовуйте свої облікові дані для входу в систему DeapSeaK

2Виберіть спосіб доступу
  • Головна сторінка: кнопка "QR Система"
  • Меню системи: розділ "QR Система"
  • Прямий доступ: /qr-interface.html
3Використовуйте відповідні функції

Система автоматично покаже інтерфейс відповідно до вашої ролі

Тестові користувачі

Адміністратор: admin / admin123
Диспетчер: dispatcher1 / dispatcher123
Технік: tech1 / tech123
Клієнт: client1 / client123

Адміністратор ADMIN

Доступні функції:
  • Повне управління QR-кодами
  • Розширена аналітика
  • Масове створення кодів
  • Управління користувачами
Швидкі дії:

📊 Управління QR-кодами - повний контроль
📈 Розширена аналітика - детальні звіти
⚡ Масове створення - створення для всіх ліфтів

Диспетчер DISPATCHER

Доступні функції:
  • Управління QR-кодами для ліфтів
  • Створення кодів для заявок
  • Перегляд статистики
  • Координація технічних робіт
Швидкі дії:

📋 QR-коди системи - управління кодами
🏢 QR для ліфтів - створення кодів
📝 QR для заявок - обробка запитів

Технік TECHNICIAN

  • Робота з завданнями
  • Перегляд історії сканувань
  • Швидке сканування
Швидкі дії:

📷 Сканер QR-кодів - основний інструмент
📊 Мої сканування - історія дій
⚡ Швидке сканування - миттєвий доступ

Клієнт CLIENT

Доступні функції:
  • Сканування QR-кодів ліфтів
  • Подача заявок
  • Повідомлення про проблеми
  • Отримання інформації
Швидкі дії:

📱 Сканувати QR ліфта - отримання інформації

Корисні поради

Сканування
  • Переконайтеся, що камера має доступ
  • Тримайте QR-код в центрі кадру
  • Забезпечте достатнє освітлення
  • Можна завантажити файл з QR-кодом
Мобільний доступ
  • Система адаптована для мобільних
  • Використовуйте основну камеру
  • Поверніть пристрій вертикально
  • Стабільний інтернет обов'язковий
Проблеми
  • Перевірте права доступу до камери
  • Оновіть сторінку при помилках
  • Зверніться до адміністратора
  • Використовуйте підтримуваний браузер
