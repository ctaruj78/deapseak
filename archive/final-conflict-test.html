🔧 Фінальні виправлення конфліктів

Виявлені глибші проблеми:
  1. 🎭 Конфлікт обробників: Дві функції на одну кнопку (HTML + JS)
  2. 🔒 Заблоковані поля: Неможливо ввести текст в поля інспектора
  3. 🔄 Різні модальні вікна: При повторному відкритті - інше вікно
  4. 🎨 CSS конфлікти: Стилі блокують взаємодію з полями
Фінальні виправлення:
  1. ✅ Видалено конфлікт обробників: Залишено тільки один в HTML
  2. ✅ Радикально розблоковано поля: Примусове зняття disabled/readonly
  3. ✅ Радикальне закриття: Повне очищення backdrop'ів та класів
  4. ✅ CSS override: Стилі з максимальним пріоритетом

🧪 Що тестувати

Сценарій тестування:
  1. Відкрийте сторінку ліфтів
  2. Клікніть на ліфт → модальне вікно
  3. Натисніть "Додати звіт інспекції"
  4. Тест 1: Спробуйте ввести ім'я інспектора
  5. Тест 2: Спробуйте ввести коментарі
  6. Тест 3: Натисніть "Скасувати"
  7. Тест 4: Повторно відкрийте звіт інспекції
  8. Перевірте: Чи з'являється те ж саме вікно?

document.body.className = document.body.className.replace(/modal-open/g, '');
