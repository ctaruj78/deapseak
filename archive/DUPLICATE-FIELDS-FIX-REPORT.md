# 🔧 Звіт про виправлення дублікатів полів ТО

## Виявлена проблема

Ви були абсолютно праві щодо дублікатів! В модальному вікні звіту інспекції було поле `nextInspectionDue` ("Наступна інспекція до"), яке дублювало функціональність поля `nextMaintenance` з основного модального вікна ліфта.

### Проблемні дублікати:
- **Основне модальне вікно:** `lastMaintenance` / `nextMaintenance` 
- **Модальне вікно звіту інспекції:** `nextInspectionDue` ❌ **ДУБЛІКАТ**

## Виконане виправлення

### ✅ Видалено дублікат
Поле `nextInspectionDue` видалено з модального вікна звіту інспекції.

### ✅ Замінено на логічну альтернативу
Замість ручного введення дублікуючої дати, додано:

```html
<!-- Автоматичне оновлення -->
<div class="custom-control custom-checkbox">
    <input type="checkbox" class="custom-control-input" id="updateMaintenanceDates" checked>
    <label class="custom-control-label" for="updateMaintenanceDates">
        Оновити дати ТО в основній інформації ліфта
    </label>
</div>

<!-- Вибір періодичності -->
<select class="form-control" id="maintenanceFrequencyOverride">
    <option value="">Використати стандартну (з налаштувань ліфта)</option>
    <option value="3">Через 3 місяці</option>
    <option value="6">Через 6 місяців</option>
    <option value="12">Через 12 місяців</option>
    <option value="24">Через 24 місяці</option>
</select>
```

### ✅ Додано автоматичну логіку
Тепер коли користувач додає звіт інспекції:

1. **Дата інспекції** автоматично стає **"Останнє ТО"** в основних даних ліфта
2. **"Наступне ТО"** розраховується автоматично на основі обраної періодичності
3. Основні дані ліфта оновлюються автоматично
4. Таблиця ліфтів перезавантажується з новими даними

## Технічні зміни

### Файли змінено:
- `/pages/admin/lifts.html` - оновлено HTML модального вікна звіту інспекції
- Додано JavaScript функцію `updateLiftMaintenanceDates()`
- Оновлено функцію `saveInspectionReport()`

### Нова логіка:
```javascript
// Розрахунок наступної дати ТО
if (shouldUpdateMaintenance) {
    const inspectionDateObj = new Date(inspectionDate);
    const frequencyMonths = frequencyOverride ? parseInt(frequencyOverride) : 6;
    
    calculatedNextMaintenance = new Date(inspectionDateObj);
    calculatedNextMaintenance.setMonth(calculatedNextMaintenance.getMonth() + frequencyMonths);
}

// Автоматичне оновлення основних даних ліфта
updateLiftMaintenanceDates(liftId, inspectionDate, calculatedNextMaintenance);
```

## Переваги рішення

### ✅ Автоматизація

- Автоматичний розрахунок наступної дати ТО
