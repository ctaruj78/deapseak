### Додані функції:

#### 1. getUserRole()
```javascript
function getUserRole() {
    try {
        const token = localStorage.getItem('authToken');
        if (!token) return null;
        
        const payload = JSON.parse(atob(token.split('.')[1]));
        return payload.role || null;
    } catch (error) {
        console.error('❌ Помилка парсингу токена:', error);
        return null;
    }
}
```

#### 2. Modified deleteLift()
```javascript
async function deleteLift(liftId) {
    const userRole = getUserRole();
    
    if (userRole === 'dispatcher') {
        // Модерація: відправити запит
        if (confirm('Відправити запит на видалення? Адмін підтвердить.')) {
            await apiCall(`/api/lifts/${liftId}/request-deletion`, 'POST');
            alert('✅ Запит відправлено!');
            // Візуально позначити
            markAsPendingDeletion(liftId);
        }
    } else {
        // Admin: видалити одразу
        if (confirm('Видалити назавжди?')) {
            await apiCall(`/api/lifts/${liftId}`, 'DELETE');
            alert('✅ Видалено!');
            refreshList();
        }
    }
}
```

1. Натиснути **"Додати ліфт"**

4. Вказати кількість: `3`
5. Натиснути **"Створити всі"**

**Результат:**
```
✅ Ліфт #1: Rua da Liberdade 45, Apt. 1

✅ Ліфт #3: Rua da Liberdade 45, Apt. 3

### Другий муніципальний номер:

1. Відкрити **Enhanced Modal**
2. Вкладка **"Загальна інформація"**
3. Заповнити:
   - Муніципальний номер #1: `12345` (обов'язкове)
   - Муніципальний номер #2: `67890` (опціонально)

**Використання:**
- Деякі будівлі мають 2 номери для одного ліфта

```

🗑️  - Запит на видалення (3 секунди)
📋  - Показати QR (миттєво)
📁  - Документи (2 секунди)

### Видалення з модерацією:

1. Dispatcher натискає **🗑️ Видалити**
2. Підтверджує: "Відправити запит на видалення?"
3. Система відправляє запит → admin отримує notification
4. Ліфт візуально позначається **"Pending Deletion"** (жовтий border, pulsating badge)
5. Admin отримує email:
```
Тема: [FestLift] Запит на видалення ліфта
Від: Dispatcher João Silva
Ліфт: Rua da Paz 23, #12345
Причина: Ліфт демонтовано, будівлю знесено
Дія: [Підтвердити] [Відхилити]
```
6. Admin натискає "Підтвердити" → ліфт видаляється
7. Dispatcher отримує notification: "✅ Ваш запит підтверджено. Ліфт #12345 видалено."
