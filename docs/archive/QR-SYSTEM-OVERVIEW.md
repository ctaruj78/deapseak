## 🔧 Проблеми які треба виправити

### 1. CDN бібліотеки не працюють в Codespaces
```html
<!-- ❌ НЕ ПРАЦЮЄ: -->
<script src="https://cdn.jsdelivr.net/npm/qrcode@1.5.1/build/qrcode.min.js"></script>

<!-- ✅ ТРЕБА ЗАМІНИТИ НА: -->
<script src="/assets/libs/qrcodejs.min.js"></script>
```
**Знайдено в:** qr-generator.html, generator.html (мінімум)

### 2. Неправильний API
```javascript
// ❌ ЗАРАЗ (не працює):
new QRCode(container, {
    colorDark: "#000000",     // qrcodejs НЕ підтримує
    correctLevel: QRCode.CorrectLevel.H  // qrcodejs НЕ підтримує
});

// ✅ ТРЕБА:
new QRCode(container, {
    text: data,
    width: 128,
    height: 128
});
```
**Знайдено в:** qr.js (QRManager клас)

### 3. Формат даних без адреси
```javascript
// ❌ ЗАРАЗ:
{
    liftId: "123",
    serial: "ABC"
    // Диспетчер НЕ знає де технік!
}

// ✅ ТРЕБА:
{
    id: "CML-123",
    lift: 1,
    addr: "вул. Шевченка, 10"  // ← Диспетчер бачить локацію!
}
```
