## 📝 Чому це потрібно?

GitHub Codespaces **за замовчуванням** робить порти **Private**.

Це означає:
- ✅ `curl` з терміналу працює (localhost)
- ❌ Браузер НЕ може робити fetch між портами
- ❌ Різні порти = різні домени = CORS блокує

**Рішення:** Зробити порт 3001 **Public**!
