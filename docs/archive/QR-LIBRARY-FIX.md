# 🔧 ВИПРАВЛЕННЯ: Бібліотека QR-коду не завантажується

## ❌ Проблема
При спробі генерації QR-коду з'являється помилка:
```
❌ Бібліотека QR-коду не завантажена
```

---

## ✅ Виправлення застосовано

### 1. Додано множинні CDN джерела
**Файл:** `pages/admin/lifts.html`

```html
<!-- Основний CDN -->
<script src="https://cdn.jsdelivr.net/npm/qrcode@1.5.3/build/qrcode.min.js"></script>

<!-- Резервне завантаження якщо основний CDN не працює -->
<script>
    setTimeout(function() {
        if (typeof QRCode === 'undefined') {
            // Завантажуємо з альтернативного джерела
            var script = document.createElement('script');
            script.src = 'https://unpkg.com/qrcode@1.5.3/build/qrcode.min.js';
            document.head.appendChild(script);
        }
    }, 2000);
</script>
```

### 2. Покращено систему очікування
- Збільшено час очікування до 5 секунд (50 спроб по 100ms)
- Додано лічильник спроб
- Додано повідомлення про помилку після максимуму спроб

### 3. Додано діагностичну сторінку
**Файл:** `test-qrcode-library.html`

Ця сторінка:
- ✅ Перевіряє чи завантажується QRCode
- ✅ Показує доступні методи
- ✅ Дозволяє протестувати генерацію

## 🔍 Можливі причини проблеми

### 1. Інтернет-з'єднання
**Симптом:** Бібліотека не завантажується з CDN  
**Рішення:** Перевірити з'єднання з інтернетом

### 2. Блокування браузером
**Симптом:** Скрипти блокуються розширеннями  
**Рішення:** 
- Вимкнути AdBlock/блокувальники
- Додати localhost до винятків

### 3. CDN недоступний
**Симптом:** jsdelivr.net не відповідає  
**Рішення:** Система автоматично спробує unpkg.com

### 4. Завантаження ще не завершене
**Симптом:** Бібліотека завантажується повільно  
**Рішення:** Система чекає до 5 секунд автоматично

## 🛠️ Ручне виправлення

### Якщо бібліотека все одно не завантажується:

1. **Оновити сторінку з очищенням кешу:**
   ```
   Ctrl + Shift + R  (Windows/Linux)
   Cmd + Shift + R   (Mac)
   ```

2. **Очистити кеш браузера:**
   - Chrome: Settings → Privacy → Clear browsing data
   - Firefox: Options → Privacy → Clear Data

3. **Перевірити консоль на помилки:**
   - F12 → Console
   - Шукати червоні повідомлення про помилки

4. **Спробувати інший браузер:**
   - Chrome / Firefox / Edge
