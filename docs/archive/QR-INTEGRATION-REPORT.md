# QR Система - Інтеграція між ролями

## Перевірка повної інтеграції QR системи

### 1. API Endpoints (✅ ПОВНІСТЮ ІНТЕГРОВАНО)

| Endpoint | Метод | Функція | Доступ |
|----------|-------|---------|---------|
| `/api/qr/codes` | GET | Список QR-кодів з фільтрацією | Всі авторизовані |
| `/api/qr/codes/:id` | GET | Деталі конкретного QR-коду | Всі авторизовані |
| `/api/qr/codes` | POST | Створення/оновлення QR-коду | Admin, Dispatcher |
| `/api/qr/codes/:id` | DELETE | Видалення QR-коду | Admin |
| `/api/qr/bulk-create-lift-codes` | POST | Масове створення для ліфтів | Admin |
| `/api/qr/scan` | POST | Сканування QR-коду | Всі |
| `/api/qr/stats` | GET | Статистика QR-системи | Admin, Dispatcher |
| `/api/qr/scans` | GET | Історія сканувань | Всі авторизовані |

### 3. Взаємодія між ролями через QR систему

#### Сценарій 1: Створення та обслуговування ліфта
1. **Адмін** створює QR-код для нового ліфта
2. **Диспетчер** призначає технічне обслуговування через QR
3. **Технік** сканує QR-код та виконує роботи
4. **Клієнт** може відсканувати QR для інформації/скаржі

#### Сценарій 2: Аварійна ситуація
1. **Клієнт** сканує QR ліфта та повідомляє про проблему
2. **Диспетчер** отримує сповіщення та створює термінове завдання
3. **Технік** отримує завдання та сканує QR для деталей
4. **Адмін** моніторить процес через аналітику
