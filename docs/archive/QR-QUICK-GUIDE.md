# 🚀 Швидкий посібник: Генерація QR-кодів для ліфтів

## 📱 Для одного ліфта

### Крок 1: Відкрийте форму додавання ліфта
- Перейдіть на сторінку "Управління ліфтами"
- Натисніть кнопку **"Додати ліфт"**

### Крок 2: Заповніть базову інформацію
```
Муніципальний № *: [введіть номер, наприклад: LIFT-001]
Адреса: [введіть адресу]
Кількість ліфтів: 1
```

### Крок 3: Згенеруйте QR-код
- Натисніть кнопку **🔲 QR** біля поля "Муніципальний №"
- QR-код з'явиться нижче у красивому фіолетовому контейнері

### Крок 4: Збережіть або роздрукуйте
- Натисніть **📥 PNG** для завантаження QR як зображення
- Натисніть **🖨️ Друк** для друку QR-коду

---

## 🏢 Для декількох ліфтів

### Крок 1: Вкажіть кількість
```
Кількість ліфтів: [2, 3, 4, ... до 20]
```

### Крок 2: Заповніть номери
З'являться додаткові поля:
```
Ліфт 1: LIFT-001 [Основний]
Ліфт 2: LIFT-002 [+ Генерувати QR-код]
Ліфт 3: LIFT-003 [+ Генерувати QR-код]
...
```

### Крок 3: Згенеруйте QR для кожного
- Для ліфта 1: натисніть кнопку біля основного поля
- Для ліфтів 2+: натисніть "Генерувати QR-код" у відповідному рядку
- Кожен QR з'явиться у своєму контейнері

### Крок 4: Збережіть всі QR
- Кожен QR має свої кнопки завантаження/друку
- Можна завантажити окремо або роздрукувати разом

---

## 🎯 Що містить QR-код?

```json
{
  "municipalNumber": "LIFT-001",
  "address": "вул. Хрещатик, 1, Київ",
  "liftNumber": 1,
  "createdAt": "2025-10-12T...",
  "accessUrl": "https://deapseak.com/lift-access.html?id=LIFT-001"
}
```

При скануванні QR-коду користувач переходить на сторінку доступу до ліфта.

## ❓ Поширені проблеми та рішення

### Проблема: QR не генерується
**Рішення:**
1. Перевірте чи заповнено муніципальний номер
2. Перевірте інтернет-з'єднання (потрібна бібліотека QRCode)
3. Оновіть сторінку (F5)
4. Перевірте консоль браузера (F12)

### Проблема: Відображається порожній квадрат
**Рішення:**
- Це виправлено! Якщо бачите - оновіть файл `enhanced-lift-modal.js`

### Проблема: Кнопка не працює
**Рішення:**
1. Перевірте що кількість ліфтів встановлена правильно
2. Перевірте що поле муніципального номера не порожнє
3. Почекайте завантаження всіх скриптів (2-3 секунди)

- Розмір: 150x150 px

- Прозорість: Ні

- Орієнтація: Портрет

## 💡 Поради

1. **Використовуйте унікальні номери** - кожен ліфт має мати унікальний муніципальний номер

2. **Збережіть QR-коди** - після генерації завантажте всі QR-коди для резервного копіювання

3. **Роздрукуйте та розмістіть** - розмістіть QR-код біля кожного ліфта на видному місці

4. **Тестуйте QR** - після друку просканируйте QR телефоном для перевірки

5. **Оновлюйте при змінах** - якщо змінюється інформація про ліфт, згенеруйте новий QR
