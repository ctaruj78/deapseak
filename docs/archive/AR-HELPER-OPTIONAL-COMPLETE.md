## 🚀 **Як це працює:**

### **При першому завантаженні:**
```javascript

settings = { arHelper: false }
```

- ❌ **Якщо AR вимкнено:** "Налаштування" (веде в system-settings.html)
- ⚠️ **Якщо AR недоступний:** "Smart Helper" (fallback функції)

### **Користувач може:**
1. Відкрити налаштування через кнопку "⚙️ Налаштування"
2. Увімкнути/вимкнути AR Helper перемикачем
3. Протестувати AR функціональність
4. Налаштування зберігаються в `localStorage`

## 💾 **Технічні деталі:**

### **localStorage структура:**
```javascript
{
  "deapseak_settings": {
    "arHelper": false,           // AR Helper вимкнено
    "voiceControl": false,       // Голосове управління
    "analytics": true,           // Аналітика
    "pushNotifications": true,   // Push сповіщення  
    "soundNotifications": true,  // Звукові сповіщення
    "emailNotifications": false  // Email сповіщення
  }
}
```

### **AR Helper стани:**
- **Disabled:** `window.arHelper = null`
- **Fallback:** `window.arHelper = fallback instance`  
- **Full AR:** `window.arHelper = full DeapSeaKARHelper instance`

### **Глобальні функції:**
- `window.enableARHelper()` - Увімкнути AR
- `window.disableARHelper()` - Вимкнути AR
- `openSystemSettings()` - Відкрити налаштування
