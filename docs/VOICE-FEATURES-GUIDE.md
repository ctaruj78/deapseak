# 🎤 Голосові функції AI чату - Інструкція

## 📋 Огляд

AI чат DeapSeaK тепер підтримує **голосове введення** та **озвучування відповідей** для зручнішої роботи, особливо для технічних спеціалістів на об'єктах.

---

## 🎤 Голосове введення (Speech-to-Text)

### Як використовувати:

1. **Натисніть кнопку мікрофона** 🎤 (фіолетова, поруч з полем вводу)
2. **Говоріть** португальською мовою вашу відповідь
3. **Текст автоматично розпізнається** та з'явиться в полі вводу
4. **Питання автоматично відправиться** до AI

### Візуальні індикатори:

- **Фіолетова кнопка** 🎤 - готова до запису
- **Червона пульсуюча кнопка** 🔴 - йде запис
- **Іконка зупинки** ⏹️ - під час запису

### Підтримувані мови:

- 🇵🇹 **Португальська** (pt-PT) - основна мова
- 🇺🇦 Українська - може розпізнавати базові слова
- 🇬🇧 Англійська - технічні терміни

### Приклади команд:

```
"Código E01"
"porta não fecha"
"motor parado"
"cabos quebrados"
"что такое para-quedas"
"перевірка гальма"
```

## 🔊 Озвучування відповідей (Text-to-Speech)

### Як використовувати:

1. **Отримайте відповідь** від AI
2. **З'явиться зелена кнопка динаміка** 🔊
3. **Натисніть кнопку** - відповідь буде озвучена
4. **Натисніть знову** щоб зупинити

### Візуальні індикатори:

- **Зелена кнопка** 🔊 - готова озвучити
- **Червона кнопка** 🔴 - йде озвучування
- **Іконка зупинки** ⏹️ - під час озвучування

### Параметри озвучування:

- **Мова:** Португальська (pt-PT)
- **Швидкість:** 0.9x (90% нормальної швидкості)
- **Тон:** Нормальний
- **Очистка:** Автоматично прибирає Markdown форматування

### Що озвучується:

✅ Весь текст відповіді AI  
✅ Технічні терміни  
✅ Номери статей законів  
✅ Інструкції  
❌ Код (автоматично пропускається)  
❌ Markdown розмітка (очищається)

## 🌐 Технічні деталі

### Підтримка браузерів:

| Браузер | Голосове введення | Озвучування |
|---------|-------------------|-------------|
| Chrome ✅ | Повна підтримка | Повна підтримка |
| Edge ✅ | Повна підтримка | Повна підтримка |
| Safari ✅ | WebKit підтримка | Повна підтримка |
| Firefox ⚠️ | Обмежена | Повна підтримка |
| Mobile Chrome ✅ | Так | Так |
| Mobile Safari ✅ | Так | Так |

### API використання:

**Speech Recognition:**
```javascript
const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
speechRecognition.lang = 'pt-PT';
speechRecognition.continuous = false;
```

**Speech Synthesis:**
```javascript
const utterance = new SpeechSynthesisUtterance(cleanText);
utterance.lang = 'pt-PT';
utterance.rate = 0.9;
```

### Graceful Degradation:

Якщо браузер **НЕ підтримує** голосові функції:
- ✅ Кнопка мікрофона автоматично вимикається
- ✅ Показується повідомлення "Voice input not supported"
- ✅ Текстовий ввід продовжує працювати
- ✅ Немає помилок або крашів

## 📱 Використання на мобільних

### Android (Chrome):

1. **Дозвольте доступ** до мікрофона при першому натисканні
2. **Говоріть чітко** після появи індикатора
3. **Чекайте 1-2 секунди** після закінчення фрази

### iOS (Safari):

1. **Дозвольте доступ** до мікрофона в налаштуваннях Safari
2. **Натисніть мікрофон** і почніть говорити
3. **Safari автоматично зупинить** запис після паузи

### Поради для кращого розпізнавання:

✅ Говоріть чітко і не швидко  
✅ Тримайте пристрій на відстані 15-30см  
✅ Уникайте шумних місць (машинні відділення)  
✅ Використовуйте технічні терміни португальською  
✅ Коди помилок говоріть по літерах: "E zero um"

## 🔒 Безпека та приватність

### Дані не зберігаються:

- ✅ Голос **НЕ записується** на сервер
- ✅ Розпізнавання **локально в браузері** (Chrome Web Speech API)
- ✅ Тільки текст відправляється до AI
- ✅ Немає передачі аудіо через мережу

### Дозволи:

- 🎤 Доступ до мікрофона - **тільки під час активного використання**
- 🔊 Озвучування - **не потребує дозволів**

---

## 🐛 Вирішення проблем

### Мікрофон не працює:

1. ✅ **Перевірте дозволи** браузера на доступ до мікрофона
2. ✅ **Спробуйте інший браузер** (Chrome рекомендовано)
3. ✅ **Перезавантажте сторінку**
4. ✅ **Перевірте апаратний мікрофон** в системних налаштуваннях

### Озвучування не працює:

1. ✅ **Перевірте гучність** пристрою
2. ✅ **Вимкніть режим без звуку** (mobile)
3. ✅ **Спробуйте іншу відповідь AI**
4. ✅ **Оновіть браузер** до останньої версії

### Погане розпізнавання:

1. ✅ **Говоріть португальською** - це основна мова
2. ✅ **Уникайте шуму** навколо
3. ✅ **Говоріть повільніше** і чіткіше
4. ✅ **Використовуйте стандартні терміни**

### Кнопка мікрофона сіра:

- ⚠️ Ваш браузер **не підтримує** Web Speech API
- ✅ Використовуйте **Chrome, Edge або Safari**
- ✅ Текстовий ввід завжди доступний
