# 🖱️ Drag-to-Scroll - Швидкий старт

## Для додавання на нову сторінку:

### 1. Додайте у `<head>`:
```html
<link rel="stylesheet" href="/assets/css/table-drag-scroll.css">
```

### 2. Додайте перед `</body>`:
```html
<script src="/assets/js/table-drag-scroll.js"></script>
```

### 3. Використовуйте `.table-responsive`:
```html
<div class="table-responsive">
    <table class="table">
        <!-- Ваша таблиця -->
    </table>
</div>
```

**Готово!** Drag-to-scroll активується автоматично 🎉

---

## Або використайте скрипт для ВСІХ сторінок:

```bash
./add-drag-scroll-to-all-pages.sh
```

Це автоматично додасть компонент на всі HTML сторінки з таблицями.
