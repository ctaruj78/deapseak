## 🔧 Як використовувати

### Варіант 1: Ручне копіювання

1. Відкрийте файл, який потрібно виправити
2. Знайдіть секцію `<nav class="mt-2">...</nav>`
3. Скопіюйте вміст з відповідного еталонного файлу
4. Вставте замість старого меню
5. Додайте `class="nav-link active"` до поточної сторінки

### Варіант 2: Автоматичне оновлення (bash)

```bash
# Admin files
for file in pages/admin/*.html; do
    # Замінити секцію nav у кожному файлі
    sed -i '/<nav class="mt-2">/,/<\/nav>/c\' "$file"
    cat templates/sidebar-admin-canonical.html >> "$file"
done
```

## 🚀 Швидкі команди

### Перевірити скільки файлів потребують оновлення

```bash
# Admin
grep -L "Unified Analytics" pages/admin/*.html | wc -l

# Tech  
grep -L "База знань" pages/tech/*.html | wc -l

# Dispatcher
grep -L "Налаштування" pages/dispatcher/*.html | wc -l

# Client
grep -L "Документація" pages/client/*.html | wc -l
```

### Знайти файли з відносними шляхами

```bash
grep -r 'href="[^/].*\.html"' pages/ | cut -d: -f1 | sort -u
```

### Підрахувати пункти меню в файлі

```bash
grep -c 'class="nav-link"' pages/admin/settings.html
```
