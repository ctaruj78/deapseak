## 🔌 API Endpoints що тестуються

### Аутентифікація
- `POST /api/auth/login` - Вхід в систему
- `POST /api/auth/register` - Реєстрація
- `GET /api/verify-token` - Перевірка токена

### Ліфти
- `GET /api/lifts` - Список ліфтів ✅
- `POST /api/lifts` - Створення ліфта
- `PUT /api/lifts/:id` - Оновлення
- `DELETE /api/lifts/:id` - Видалення

### Заявки
- `GET /api/requests` - Список заявок ✅
- `POST /api/requests` - Створення заявки
- `PUT /api/requests/:id` - Оновлення статусу

### Користувачі
- `GET /api/users` - Список користувачів
- `POST /api/users` - Створення користувача
- `PUT /api/users/:id` - Оновлення профілю

### Призначення
- `GET /api/assignments` - Список призначень ✅
- `POST /api/assignments` - Створення призначення

## 🚀 Як використовувати

### Швидка демонстрація:
1. Відкрийте http://localhost:8080/demo.html
2. Натисніть будь-яку кнопку для тесту функції
3. Переглядайте результати в реальному часі

### Повне тестування:
1. Відкрийте http://localhost:8080/simulator.html  
2. Натисніть "Повна симуляція"
3. Спостерігайте за прогресом
4. Переглядайте детальні логи

### Командний рядок:
```bash
# Запуск автоматизованого тесту
./test-all-system.sh

# Швидка перевірка статусу
curl http://localhost:3001/api/status
```

## 🔧 Технічні деталі

### Архітектура:
- **Frontend:** HTML5, Bootstrap 5, JavaScript ES6+
- **Backend:** Node.js Express API
- **Database:** MongoDB
- **Auth:** JWT токени
- **UI Framework:** AdminLTE

### Залежності:
- QRCode.js для генерації QR кодів
- Font Awesome для іконок

### Безпека:
- JWT аутентифікація
- Ролевий доступ
