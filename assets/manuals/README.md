# 📖 Технічні інструкції та мануали

## Структура:

- `programming/` - Інструкції програмування контролерів
  - `monarch/` - Monarch NICE-3000 та інші
  - `fermator/` - Fermator VVVF Series
  - `invt/` - INVT GD-10 Lift Inverter
  - `yaskawa/` - Yaskawa L1000A
  - `generic-controllers/` - Універсальні інструкції

## Формат файлів:

- **PDF** - мануали виробників (Portuguese preferred)
- **XLSX** - таблиці параметрів
- **MD** - швидкі довідники

## Приклад структури мануала:

```
📁 monarch/
├── nice-3000-programming-PT.pdf          (Офіційний мануал португальською)
├── nice-3000-parameter-list.xlsx         (Excel з усіма параметрами)
├── nice-3000-quick-setup.pdf             (Швидке налаштування - 2 сторінки)
├── nice-3000-error-codes.pdf             (Коди помилок з діагностикою)
└── nice-3000-common-parameters.md        (Типові параметри Markdown)
```

## Типові параметри (приклад):

### NICE-3000 Базові налаштування:

| Параметр | Значення | Опис |
|----------|----------|------|
| F0-01 | 50 Hz | Частота живлення (Європа) |
| F0-02 | 1 | Джерело команди (Терминал) |
| F0-03 | 50 Hz | Швидкість 1 (1.0 m/s) |
| F0-10 | 0.8 m/s² | Прискорення |
| F0-11 | 0.8 m/s² | Сповільнення |
| F2-01 | 8.5 A | Номінальний струм двигуна |
| F2-02 | 4.0 kW | Номінальна потужність |
| A0-01 | 500 kg | Вага кабіни |
| A0-02 | 630 kg | Вантажопідйомність |
