🏛️ **DGE - ГОЛОВНИЙ РЕГУЛЯТОР** ⭐⭐⭐⭐⭐

- **Статус:** Державний орган, відповідальний за ліфти
- **URL:** https://www.dgeg.gov.pt
- **Секції:**
  - `/areas-setoriais/.../elevadores/` - Ліфти
  - `/legislacao/` - Законодавство
  - `/elevadores/inspecoes/` - Інспекції

📰 **Додаткові джерела:**
- 📖 Diário da República - офіційна газета
- 🏛️ ASAE - інспекції
- 👮 ACT - безпека праці

**Створені файли:**
```

/logs/regulations-check-report.json     - JSON звіти
/logs/admin-notifications.json          - Сповіщення адмінам
```

**API Endpoints:**
- `POST /api/regulations/check-updates` - запустити перевірку (тільки адміни)
- `GET /api/regulations/last-check` - останній звіт

**UI в AI Асистенті:**

## 🚀 Як використовувати

### Для користувачів:

1. **Відкрити AI Асистент:**
   - Admin: `/pages/admin/ai-assistant-full.html`
   - Tech: `/pages/tech/ai-assistant.html`
   - Client: `/pages/client/ai-assistant.html`
   - Dispatcher: `/pages/dispatcher/ai-assistant.html`

2. **Побачити Google Gemini брендинг:**
   - Заголовок: "AI Асистент DeapSeaK"
   - Підзаголовок: "Powered by Google Gemini 2.5 Flash" 🌈

3. **Перевірити оновлення законів:**
   - Вкладка "Норми PT"
   - Кнопка "🔄 Перевірити оновлення"
   - Почекати 5-30 секунд
   - Побачити результат

### Для адміністраторів:

**Ручна перевірка:**
```bash
node services/regulations-updater.js
```

**API виклик:**
```bash
curl -X POST http://localhost:5000/api/regulations/check-updates \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

**Автоматична перевірка (щодня о 03:00):**
```bash
crontab -e
# Додати:
0 3 * * * /workspaces/deapseak/cron-check-regulations.sh
```

**Переглянути логи:**
```bash
tail -f logs/regulations-updates.log
cat logs/regulations-check-report.json | jq '.'
```
